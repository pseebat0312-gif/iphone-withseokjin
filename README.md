## 项目介绍

WITH-YOU 尝试把互动小说与手机操作体验结合起来：故事不只发生在单一对话框中，还可以通过不同应用中的内容与通知逐步展开。

## 主要体验

- **手机式界面**：以移动端交互为核心的网页体验。
- **多应用叙事**：通过聊天、社交动态等不同界面呈现故事线索。
- **分支剧情**：玩家的选择可能影响后续事件和人物关系。
- **跨应用事件**：剧情可以通过消息、通知和其他应用内容相互关联。

具体功能以当前部署版本为准。

## 本地运行

请先安装 Node.js，再在项目根目录执行：

