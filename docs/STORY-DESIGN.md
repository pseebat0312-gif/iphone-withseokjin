# 八幕因果图 · 已实现的紧凑主线

全部为架空成年角色的虚构私人事件。节点内选择改变实际事件、公开内容和长期变量。主线从暧昧开始，第三幕明确确认，后半段保留情侣生活。

```mermaid
flowchart TD
 A["一 · 评论删除 / 好友点破"] --> B{"赴约还是改期"}
 B --> C["当晚私人预约"]
 B --> D["先处理自己的安排 · 次日预约"]
 C --> E["二 · 咖啡馆当面约会"]
 D --> E
 E --> F{"三 · 告白"}
 F --> G["明确答应"]
 F --> H["再次见面并协商边界"]
 G --> I["四 · 情侣日常 / 泰亨柾国 / 个人工作"]
 H --> I
 I --> J{"放映室 / 一起做饭"}
 J --> K["五 · 灯牌猜测 · X 原帖"]
 K --> L{"沉默 / 日期澄清 / 问朋友"}
 L --> M["IG 私信请求与边界"]
 M --> N{"朋友聚餐 / 两人独处"}
 N --> O["六 · 临时录制冲突 · 玩家开幕"]
 O --> P{"未知来电"}
 P --> Q["拒接 · 留证"]
 P --> R["接听 · 不透露信息"]
 Q --> S["七 · 虚构娱乐号拼图预告"]
 R --> S
 S --> T{"继续保密 / 可信朋友圈"}
 T --> U["核对原图 · 撤下错误拼图"]
 U --> V["八 · 关系与朋友收束 · 幸福结局"]
 V --> W["14 段可定时触发的情侣日常"]
```

- 不赴聚餐，不会出现露台上泰亨的表露或柾国厨房对话。
- 不公开澄清，不会凭空生成玩家澄清帖。
- 拒接来电，不会执行接听中对方的对白。
- 改期保留 declined 和专属消息；之后见面明确是改过的预约。
- 工作/帮朋友/休息、隐私策略、可信朋友圈和重要早期记忆保存在 flags/choices，结局有对应差异。
- 主线的完整收束发生在 r-finale。旧第一阶段的 checkpoint 现为继续点，不删除其选择历史。
- 手机通知指向先存储的内容，跨 App 不依赖实时生成；App 顶部或浮动的继续入口避免盲找。
